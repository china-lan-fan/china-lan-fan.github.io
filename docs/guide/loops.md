# 循环语句

凡语言提供四种循环。

## 当循环

`当 条件 循环 … 结束`：条件为真时反复执行，先判断条件：

```凡
变量 计数 = 0

当 计数 小于 5 循环
    打印(计数)
    计数 = 计数 加 1
结束
```

条件必须是布尔。

## 重复 … 直到

`重复 … 直到 条件 结束`：先执行一次循环体，再判断条件，条件为真时停止（类似 do-while）：

```凡
变量 n = 0

重复
    打印(n)
    n = n 加 1
直到 n 大于等于 3 结束
```

## 重复 N 次

`重复 N 次 … 结束`：按固定次数执行：

```凡
重复 3 次
    打印("你好")
结束
```

次数也可以是表达式：

```凡
变量 次数 = 2
重复 次数 加 1 次
    打印("一行")
结束
```

## 遍历循环

`遍历 集合 中的 元素 … 结束`：逐个访问集合中的元素。

遍历数组：

```凡
变量 名单 = ["张三", "李四", "王五"]

遍历 名单 中的 姓名
    打印(姓名)
结束
```

可以同时取序号：

```凡
遍历 名单 中的 姓名 序号
    打印(序号, "：", 姓名)
结束
```

- 序号从 `0` 开始。
- 遍历字符串时，逐个得到单字符。
- 遍历字典时，一个变量遍历值；两个变量为 `遍历 d 中的 键 值`，依次得到键和值。

```凡
遍历 "凡" 中的 字
    打印(字)
结束

变量 分数 = {"张三": 90, "李四": 85}
遍历 分数 中的 键 值
    打印(键, "->", 值)
结束
```

## 跳出与继续

- `跳出`：立即结束整个循环。
- `继续`：跳过本次循环剩余部分，进入下一轮。

```凡
变量 i = 0
当 i 小于 10 循环
    i = i 加 1
    如果 i 等于 5 那么
        跳出
    结束
    如果 i 小于 3 那么
        继续
    结束
    打印(i)
结束
```

## 长度快照

`遍历` 在开始时会对集合做长度快照：遍历过程中追加或删除元素不会改变本轮迭代次数；但元素本身被修改时，读到的是最新值。

集合是复杂表达式时建议加括号：`遍历 (甲 加 乙) 中的 项`。
