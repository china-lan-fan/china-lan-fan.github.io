# 运算

## 算术运算

| 运算 | 符号 | 中文 |
| --- | --- | --- |
| 加 | `+` | `加` |
| 减 | `-` | `减` |
| 乘 | `*` | `乘` |
| 除 | `/` | `除` |
| 取余 | `%` | `取余` |
| 取负 | `-x` | — |

```fan
打印(7 + 3)      # 10
打印(7 减 3)     # 4
打印(2 乘 5)     # 10
```

### 整数除法与提升

- 两端都是整数时，除法结果也是整数，向零截断：

```fan
打印(10 / 3)     # 3
打印(-10 / 3)    # -3
```

- 整数与小数混算，结果自动提升为小数：

```fan
打印(10 / 3.0)   # 3.3333333333333335
```

### 取余

取余只支持整数：

```fan
打印(10 % 3)     # 1
打印(5.5 取余 2) # 错误
```

### 除零

除以或对 `0` 取余会在运行时报错「除数不能为零」。

## 字符串拼接

两个字符串可以用 `+` / `加` 拼接，返回新字符串：

```fan
打印("你好" 加 "，" 加 "fan")   # 你好，fan
```

字符串不会与其他类型隐式转换：

```fan
"数量：" + 3      # 错误：加法不支持 字符串 + 整数
```

数组也可以用 `加` 拼接，详见 [数组](./arrays)。

## 比较运算

| 符号 | 中文 | 含义 |
| --- | --- | --- |
| `==` | `等于` | 相等 |
| `!=` | `不等于` | 不相等 |
| `<` | `小于` | 小于 |
| `<=` | `小于等于` | 小于等于 |
| `>` | `大于` | 大于 |
| `>=` | `大于等于` | 大于等于 |

```fan
打印(3 等于 3)     # 真
打印(2 小于 5)     # 真
打印(1 加 1 等于 2) # 真
```

- 只有同类型才能比较（整数与小数会自动提升后比较）。
- 其他跨类型比较（包括 `等于`）一律报错，不做隐式转换。
- 数组、字典使用 `等于` 做**深度比较**。
- 错误可以与 `空` 比较（用于判断有无错误）。

```fan
[1, 2] 等于 [1, 2]          # 真
{"a": 1} 等于 {"a": 1}      # 真
```

## 逻辑运算

| 符号 | 中文 | 规则 |
| --- | --- | --- |
| `&&` | `与` | 两侧都为真才为真 |
| `\|\|` | `或` | 任一侧为真即为真 |
| `!` | `非` | 取反 |

操作数必须是布尔，且支持**短路求值**：

```fan
变量 x = 真

打印(x 与 假)       # 假
打印(x 或 假)       # 真
打印(非 x)         # 假
```

短路：`与` 左侧为假时不计算右侧；`或` 左侧为真时不计算右侧。

## 优先级与括号

可以用括号明确运算顺序：

```fan
打印(1 + 2 * 3)      # 7
打印((1 + 2) * 3)    # 9
```

一元运算、括号优先于乘除，乘除优先于加减，比较次之，最后是逻辑运算。
