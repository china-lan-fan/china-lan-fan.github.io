# 数组

数组是有序元素的列表，元素可以是不同类型。

## 字面量

用方括号创建，元素以逗号分隔：

```凡
变量 空数组 = []
变量 数字 = [1, 2, 3]
变量 混合 = [1, "二", 真]
```

支持嵌套：

```凡
变量 矩阵 = [
    [1, 2, 3],
    [4, 5, 6],
]
```

字面量可以跨行，并允许尾随逗号。

## 下标访问

用 `数组[下标]` 访问元素，下标从 `0` 开始：

```凡
变量 名单 = ["张三", "李四", "王五"]

打印(名单[0])   # 张三
打印(名单[2])   # 王五
```

下标必须是整数，越界会报错：

```凡
名单[3]         # 错误：数组下标越界
```

## 修改元素

对下标位置赋值即可修改：

```凡
变量 名单 = ["甲", "乙", "丙"]
名单[0] = "丁"
打印(名单)       # [丁, 乙, 丙]
```

下标越界同样报错，不能通过越界下标新增元素。

## 拼接

用 `加` 拼接两个数组，返回**新数组**，不改变原数组：

```凡
变量 a = [1, 2]
变量 b = [3, 4]
变量 c = a 加 b

打印(c)         # [1, 2, 3, 4]
```

## 内建函数

| 函数 | 说明 |
| --- | --- |
| `长度(数组)` | 返回元素个数（也支持字符串、字典） |
| `追加(数组, 值…)` | 返回在末尾加入新元素后的新数组 |

```凡
变量 名单 = [1, 2]

打印(长度(名单))            # 2
打印(追加(名单, 3))         # [1, 2, 3]
打印(追加(名单, 3, 4, 5))   # [1, 2, 3, 4, 5]
打印(名单)                 # [1, 2]（原数组不变）
```

## 成员

数组也支持成员形式：

```凡
变量 名单 = [1, 2, 3]

打印(名单 的 长度)   # 3
打印(名单 的 反转)   # [3, 2, 1]
```

| 成员 | 说明 |
| --- | --- |
| `长度` | 元素个数 |
| `反转` | 返回元素顺序反转后的新数组 |

## 比较

用 `等于` / `不等于` 做深度比较：

```凡
打印([1, 2] 等于 [1, 2])   # 真
打印([1, 2] 等于 [1, 3])   # 假
```

## 引用语义

数组赋值传递的是引用，不做拷贝：

```凡
变量 a = [1, 2, 3]
变量 b = a
b[0] = 99
打印(a[0])       # 99
```

## 遍历

配合 `遍历` 访问元素，详见 [循环](./loops)：

```凡
遍历 [10, 20, 30] 中的 项 序号
    打印(序号, "：", 项)
结束
```
