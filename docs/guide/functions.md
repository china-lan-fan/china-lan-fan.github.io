# 函数

函数是可复用的一段代码。fan 中函数是一等值，可以赋值、传参、从函数返回。

## 定义函数

用 `函数 名(参数) … 结束`：

```fan
函数 打招呼()
    打印("你好")
结束

打招呼()
```

`定义` 关键字可以加在前面：

```fan
定义 函数 再见()
    打印("再见")
结束
```

## 参数

```fan
函数 打招呼(名字)
    打印("你好，", 名字)
结束

打招呼("小明")
```

多个参数用逗号分隔（也支持中文逗号 `，` 和顿号 `、`）：

```fan
函数 求和(a, b)
    返回 a 加 b
结束

打印(求和(2, 3))
```

## 返回值

用 `返回` 把结果返回：

```fan
函数 平方(n)
    返回 n 乘 n
结束

打印(平方(5))    # 25
```

没有 `返回` 时函数返回 `空`。

## 类型标注

参数类型写在参数名后面；返回类型用箭头 `->`（全角 `→` 也可以）：

```fan
函数 求和(a 整数、b 整数) -> 整数
    返回 a 加 b
结束

函数 问候(名字 字符串) -> 字符串
    返回 "你好，" 加 名字
结束
```

括号同时支持半角 `()` 和全角 `（）`。调用时会检查参数数量和类型；返回时检查返回值类型。

## 多返回值

`返回` 多个值（用逗号或顿号分隔）；单个返回类型直接写，多个返回类型放在括号里：

```fan
函数 商余(a 整数、b 整数) -> (整数，整数)
    返回 a / b、a % b
结束
```

### 接收多返回值

用多目标声明 / 赋值，变量数必须与返回值数一致：

```fan
变量 商、余数 = 商余(10, 3)
打印(商)      # 3
打印(余数)    # 1

变量 x = 0
变量 y = 0
x、y = 商余(7, 2)
```

### 自动展开

多返回值作为另一个函数的参数时会自动展开：

```fan
函数 相加(a 整数、b 整数)
    返回 a 加 b
结束

打印(相加(商余(10, 3)))   # 相当于 相加(3, 1) → 4
```

## 闭包

函数可以引用定义位置外层的变量，形成闭包：

```fan
函数 造计数器()
    变量 n = 0
    函数 计数()
        n = n 加 1
        返回 n
    结束
    返回 计数
结束

变量 c = 造计数器()
打印(c())    # 1
打印(c())    # 2
```

## 递归

函数可以调用自身：

```fan
函数 阶乘(n 整数) -> 整数
    如果 n 小于等于 1 那么
        返回 1
    结束
    返回 n 乘 阶乘(n 减 1)
结束

打印(阶乘(5))    # 120
```

## 匿名函数与一等值

可以不写函数名，直接作为值使用：

```fan
变量 翻倍 = 函数(n 整数) -> 整数
    返回 n 乘 2
结束

打印(翻倍(21))    # 42
```

函数也可作为参数传递：

```fan
函数 执行两次(f)
    f()
    f()
结束

执行两次(打招呼)
```

## 括号可选的调用

调用时括号通常可以省略，参数吃到行尾：

```fan
打印 "你好"
打招呼 "小明"
```

接收者形式：`名单 追加 "张三"` 等价于 `追加(名单, "张三")`。
