# 模型

模型（model）用于组织数据与行为，设计上参考 Go：

- 模型内**只定义字段**。
- 方法在模型**外部定义**，可以随时扩展。
- 通过**嵌入**复用，而不是继承。
- 不需要接口，采用鸭子类型。

`类` 关键字作为 `模型` 的兼容别名。

## 定义模型

```fan
定义 模型 矩形
    变量 整数 宽
    变量 整数 高
结束
```

字段用 `变量 [类型] 名` 声明，未指定类型时为 `任意`。字段默认值为 `空`。

## 在模型外部定义方法

语法：

```text
定义 模型 的 函数 <方法名> <模型类型> <接收者> [、其它参数] [返回类型]
    方法体
结束
```

`<模型类型>` 是模型名，`<接收者>` 是方法内代表当前对象的参数名：

```fan
定义 模型 的 函数 面积 矩形 r : 整数
    返回 r.宽 乘 r.高
结束

定义 模型 的 函数 放大 矩形 r、整数 倍数
    r.宽 = r.宽 乘 倍数
    r.高 = r.高 乘 倍数
结束
```

`定义` 和接收者等写法与普通函数一致，方法同样支持参数、返回值类型检查和多返回值。

## 实例化

用 `模型名()` 创建实例：

```fan
变量 r = 矩形()
r.宽 = 3
r.高 = 4
打印(r 的 面积())    # 12
```

### 初始化方法

如果模型定义了名为 `初始化` 的方法，实例化时会自动调用：

```fan
定义 模型 的 函数 初始化 矩形 r、整数 宽、整数 高
    r.宽 = 宽
    r.高 = 高
结束

变量 r = 矩形(3, 4)
打印(r 的 面积())
```

没有 `初始化` 方法时不能给 `模型名()` 传参。

## 访问字段与方法

`.` 和 `的` 等价：

```fan
打印(r.宽)
打印(r 的 面积())
```

- 不能给实例动态添加未声明的字段。
- 访问不存在的字段或方法会报错。

## 方法可扩展、可覆盖

方法可以在任意位置定义；后定义的同名方法会覆盖先定义的：

```fan
定义 模型 的 函数 描述 矩形 r
    返回 "旧"
结束

定义 模型 的 函数 描述 矩形 r
    返回 "新"
结束

打印(矩形().描述())    # 新
```

## 嵌入（组合）

在模型内用 `嵌入 模型名` 复用另一个模型的字段与方法：

```fan
定义 模型 人
    变量 字符串 姓名
结束

定义 模型 的 函数 问好 人 r
    返回 r.姓名
结束

定义 模型 学生
    嵌入 人
    变量 整数 学号
结束

变量 s = 学生()
s.姓名 = "小明"
s.学号 = 1
打印(s.问好())    # 小明（嵌入的字段、方法被提升）
```

嵌入的字段和方法会被提升到外层模型；命名冲突时需要显式访问。

## 鸭子类型

只要对象拥有需要的方法，就可以传入，不要求它“是”某个模型，也不需要声明接口：

```fan
函数 让它问好(东西)
    返回 东西.问好()
结束
```
