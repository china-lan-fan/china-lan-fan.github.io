# 模块

当程序变大时，可以拆分成多个文件。每个 `.fan` 文件就是一个模块，通过 `导出` 和 `导入` 组织代码。

## 导出

在定义前加 `导出`，把名字暴露给其他文件：

```fan
导出 变量 版本 = "1.0"

导出 函数 加倍(n 整数) -> 整数
    返回 n 乘 2
结束

导出 模型 点
    变量 整数 x
    变量 整数 y
结束
```

支持的写法：

- `导出 变量/常量 名 = 值`
- `导出 函数 名(…) … 结束`
- `导出 模型 名 … 结束`

没有加 `导出` 的名字只能在本文件内使用：

```fan
函数 内部辅助()
    返回 "私有"
结束
```

## 导入

用 `导入 "路径"` 加载模块。不指定名字时，模块名取路径最后一段（去掉 `.fan` 后缀）：

```fan
导入 "mathlib/运算"

打印(运算.加倍(21))
打印(运算.版本)
```

用 `作为` 指定别名：

```fan
导入 "mathlib/运算" 作为 m

打印(m.加倍(5))
```

## 使用模块成员

通过 `模块名.成员` 访问导出的变量、函数和模型：

```fan
变量 p = 运算.点()
p.x = 3
p.y = 4

运算.函数式调用()
打印(m.版本)
```

- 可以直接调用模块导出的函数：`m.加倍(2)`。
- 可以用模块导出的模型实例化：`运算.点()`。
- 访问**未导出**成员会报错：`m.内部辅助()` 不可用。

## 路径解析

- 导入路径相对于**当前运行脚本所在目录**解析。
- 可以省略 `.fan` 后缀，也可以显式写出。
- 目录用 `/` 分隔，例如 `"modules/统计/统计"`。

```fan
导入 "modules/统计/统计"
打印(统计.总和([1, 2, 3]))
```

找不到模块会报「找不到模块：…」。

## 只加载一次

同一个模块在一次运行中只会执行一次，重复导入得到的是同一个模块对象（有缓存）。

如果模块之间相互导入形成环，会检测到并报「循环导入」错误。

## 一个完整例子

模块文件 `问候/问候.fan`：

```fan
导出 变量 语言 = "中文"

导出 函数 打招呼(名字 字符串) -> 字符串
    返回 "你好，" 加 名字
结束
```

主程序：

```fan
导入 "问候/问候" 作为 hi

打印(hi.语言)
打印(hi.打招呼("fan"))
```

输出：

```text
中文
你好，fan
```
