# 错误处理

凡语言的错误处理参考 Go：**错误是值**。约定函数把 `错误` 作为最后一个返回值，没有错误时该位置为 `空`。

## 错误值

用 `错误("消息")` 创建错误，用 `.消息` 读取消息字符串：

```凡
变量 e = 错误("参数不合法")
打印(e)          # 错误：参数不合法
打印(e.消息)     # 参数不合法
```

错误也可以作为类型标注：

```凡
变量 错误 e = 空
```

## 返回值、错误

函数返回 `值, 错误`，由调用方检查：

```凡
函数 除法(a 整数、b 整数) -> (整数，错误)
    如果 b 等于 0 那么
        返回 0、错误("除数不能为零")
    结束
    返回 a / b、空
结束

变量 商、e = 除法(10, 0)
如果 e 不等于 空 那么
    打印("出错：", e.消息)
否则
    打印("结果：", 商)
结束
```

错误可以与 `空` 比较，用于判断有无错误。

## 检查：自动传播

`检查 调用` 用于简化错误处理：

- 如果调用的最后一个返回值是错误，**立即从当前函数返回该错误**（前面的返回值用对应类型的零值填充）。
- 如果没有错误，则剥掉错误位，把前面的值作为结果。

使用 `检查` 的函数，其最后一个返回类型必须是 `错误`。

```凡
函数 安全除法(a 整数、b 整数) -> (整数，错误)
    变量 结果 = 检查 除法(a, b)
    返回 结果、空
结束

变量 x、e = 安全除法(10, 0)
打印(e.消息)     # 除数不能为零
```

没有错误时：

```凡
变量 y、e2 = 安全除法(10, 2)
打印(y)          # 5
打印(e2)         # 空
```

错误传播时，前置返回值会按类型填充零值：整数 `0`、小数 `0`、字符串 `""`、布尔 `假`、数组 `[]`。

## 尝试 … 捕获

`尝试 … 捕获 [名字] … 结束` 用于兜底：捕获块内由 `检查` 传播出来的错误。

```凡
尝试
    变量 r = 检查 除法(10, 0)
    打印("不会执行到这里")
捕获 e
    打印("捕获错误：", e.消息)
结束
```

`捕获` 后的名字可省略，省略时错误对象名为 `错误`。捕获块中可以正常使用错误对象；不访问它时也可只写 `捕获`。

## 典型组合

调用链上的函数都通过 `检查` 向上传播，只在最外层用 `尝试…捕获` 或手动判断统一处理：

```凡
函数 第一层() -> (整数，错误)
    返回 检查 除法(10, 0)
结束

尝试
    变量 结果 = 检查 第一层()
    打印(结果)
捕获 e
    打印("最终处理：", e.消息)
结束
```
