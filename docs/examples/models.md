# 模型与错误

## 模型与外部方法

```fan
定义 模型 矩形
    变量 整数 宽
    变量 整数 高
结束

定义 模型 的 函数 初始化 矩形 r、整数 宽、整数 高
    r.宽 = 宽
    r.高 = 高
结束

定义 模型 的 函数 面积 矩形 r : 整数
    返回 r.宽 乘 r.高
结束

变量 r = 矩形(3, 4)
打印(r 的 面积())      # 12
```

## 嵌入

```fan
定义 模型 人
    变量 字符串 姓名
结束

定义 模型 的 函数 介绍 人 r
    返回 "我是 " 加 r.姓名
结束

定义 模型 学生
    嵌入 人
    变量 整数 学号
结束

变量 s = 学生()
s.姓名 = "小明"
s.学号 = 1
打印(s.介绍())         # 我是 小明
```

## 值、错误

```fan
函数 除法(整数 a、整数 b) : 整数、错误
    如果 b 等于 0 那么
        返回 0、错误("除数不能为零")
    结束
    返回 a / b、空
结束

变量 结果、e = 除法(10, 2)
如果 e 等于 空 那么
    打印("结果：", 结果)    # 结果： 5
结束
```

## 检查传播

```fan
函数 安全除法(整数 a、整数 b) : 整数、错误
    变量 值 = 检查 除法(a, b)
    返回 值、空
结束

变量 x、e2 = 安全除法(8, 0)
打印("错误：", e2.消息)       # 错误： 除数不能为零
```

## 尝试…捕获

```fan
尝试
    变量 r = 检查 除法(1, 0)
捕获 e
    打印("捕获：", e.消息)    # 捕获： 除数不能为零
结束
```

## 一个小综合：安全计算面积

```fan
定义 模型 的 函数 安全面积 矩形 r : 整数、错误
    如果 r.宽 小于等于 0 或 r.高 小于等于 0 那么
        返回 0、错误("宽高必须为正数")
    结束
    返回 r.宽 乘 r.高、空
结束

变量 r = 矩形(0, 4)
变量 面积、e3 = r.安全面积()
如果 e3 不等于 空 那么
    打印(e3.消息)             # 宽高必须为正数
结束
```
