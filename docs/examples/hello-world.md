# Hello World

第一个 fan 程序：

```fan
打印 "你好，fan"
```

运行：

```bash
fan run hello.fan
```

输出：

```text
你好，fan
```

## 稍微多做一点

```fan
变量 名字 = "fan"
变量 版本 = 1

打印("欢迎使用", 名字, "版本", 版本)
```

输出：

```text
欢迎使用 fan 版本 1
```

## 用函数打招呼

```fan
函数 打招呼(名字 字符串)
    打印("你好，", 名字)
结束

打招呼("小明")
打招呼("小红")
```

输出：

```text
你好， 小明
你好， 小红
```
