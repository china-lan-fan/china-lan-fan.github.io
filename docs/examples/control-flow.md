# 条件与循环

## 判断成绩等级

```凡
变量 分数 = 85

如果 分数 大于等于 90 那么
    打印("优秀")
否则如果 分数 大于等于 60 那么
    打印("及格")
否则
    打印("不及格")
结束
```

## 当循环计数

```凡
变量 i = 0
变量 和 = 0

当 i 小于等于 10 循环
    和 = 和 加 i
    i = i 加 1
结束

打印("1 到 10 的和：", 和)   # 55
```

## 重复 N 次

```凡
变量 行 = ""
重复 5 次
    行 = 行 加 "*"
结束
打印(行)                    # *****
```

## 遍历数组

```凡
变量 名单 = [10, 20, 30]

遍历 名单 中的 项 序号
    打印(序号, "：", 项)
结束
```

输出：

```text
0 ： 10
1 ： 20
2 ： 30
```

## 跳出与继续

打印 1 到 10 中的偶数，到 8 为止：

```凡
变量 n = 0
当 n 小于 10 循环
    n = n 加 1
    如果 n 等于 9 那么
        跳出
    结束
    如果 n 取余 2 等于 1 那么
        继续
    结束
    打印(n)
结束
```

输出：

```text
2
4
6
8
```
