# 数组与字典

## 数组基本操作

```fan
变量 名单 = ["张三", "李四"]

打印(长度(名单))        # 2

名单 = 追加(名单, "王五")
打印(名单)              # [张三, 李四, 王五]

打印(名单[0])           # 张三
名单[0] = "赵六"
打印(名单 的 反转)       # [王五, 李四, 赵六]
```

## 用遍历求和

```fan
变量 数字 = [1, 2, 3, 4, 5]
变量 合计 = 0

遍历 数字 中的 n
    合计 = 合计 加 n
结束

打印(合计)              # 15
```

## 数组拼接与比较

```fan
变量 a = [1, 2]
变量 b = a 加 [3, 4]

打印(b)                 # [1, 2, 3, 4]
打印(a 等于 [1, 2])     # 真
```

## 字典存取

```fan
变量 分数 = {
    "张三": 90,
    "李四": 85,
}

打印(分数["张三"])       # 90
打印(分数["王五"])       # 空

分数["王五"] = 77
打印(长度(分数))         # 3
```

## 字典键与值

```fan
变量 d = {"a": 1, "b": 2}

打印(d 的 键)            # [a, b]
打印(d 的 值)            # [1, 2]
```

## 遍历字典

```fan
变量 分数 = {"张三": 90, "李四": 85}
变量 总分 = 0

遍历 分数 中的 姓名 分
    打印(姓名, "：", 分)
    总分 = 总分 加 分
结束

打印("总分：", 总分)
```

输出：

```text
张三 ： 90
李四 ： 85
总分： 175
```

## 统计词频

```fan
变量 词表 = ["a", "b", "a", "c", "b", "a"]
变量 计数 = {}

遍历 词表 中的 词
    变量 当前 = 计数[词]
    如果 当前 等于 空 那么
        当前 = 0
    结束
    计数[词] = 当前 加 1
结束

打印(计数)              # {a: 3, b: 2, c: 1}
```
